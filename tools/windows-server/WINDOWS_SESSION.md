# הנחיות לשיחת Claude Code על שרת ה-Windows

אתה עובד על **אפליקציית Windows** של מחשבון שכר, על Windows אמיתי, בתיקייה `C:\maskoret`. קרא קודם את `CLAUDE.md`, את `CONTRIBUTING.md` ואת `flutter_app/README.md`.

## חלוקת העבודה
- **אתה:** כל מה שתלוי ב-Windows.
  - בנייה והרצה של `flutter build windows` / `flutter run -d windows`.
  - בדיקה של כל המסכים על Windows: מבנה, עברית מימין לשמאל, פונטים, תצוגה רחבה, מצב כהה, וזכוכית עם טשטוש.
  - תוכנת ההתקנה (`flutter_app/windows/installer.iss`): להתקין, להסיר, ולבדוק עדכון שקט מגרסה לגרסה.
  - קבצי `flutter_app/windows/`, ותיקון באגים שקורים רק ב-Windows.
- **שיחה אחרת על המק:** ממשיכה לבנות מסכים חדשים ב-Flutter ולבדוק אותם באנדרואיד. היא עובדת על אותו קוד, דרך GitHub.
- **שיחה שלישית על המק:** אחראית על המק, האייפון והשרת (Supabase).

## עבודה משותפת דרך git
- לפני כל עבודה: `git pull --rebase`. אחרי כל שינוי קטן ושלם: commit ו-push מיד, כדי לא להתנגש עם השיחה שעל המק.
- **לא לשנות קבצים משותפים בלי צורך.** לדוגמה מסכים ב-`flutter_app/lib/ui/` או חישובים ב-`flutter_app/lib/data/`. אם חייבים, שינוי קטן וממוקד, עם הסבר בהודעת הקומיט.
- **חישובים** (שכר, מס, "נשאר") חייבים להישאר זהים ל-Swift. אם נוגעים בהם, `flutter test` חייב לעבור.
- כל שינוי שהמשתמש ירגיש בו נרשם בעברית ב-`CHANGELOG.md` וב-`version.json` ← `notes`, תחת הגרסה הפתוחה (`"ready": false`).

## פרסום
**לא מפרסמים ולא מסמנים `"ready": true` בלי אישור מפורש של המשתמש.** הפרסום עצמו רץ אוטומטית ב-GitHub Actions.

## תקשורת
כל מה שנכתב למשתמש, כולל דיווחי התקדמות, בעברית. כשמשהו בודק את המראה, לצרף צילום מסך.

## משימה ראשונה
1. לבנות ולהריץ את אפליקציית Windows מ-main, ולעבור על כל המסכים מול המק והאייפון.
2. להתקין את תוכנת ההתקנה האחרונה מהאתר (https://maskoret.vercel.app), ולבדוק התקנה, קיצורי דרך, הסרה ועדכון שקט.
3. לדווח למשתמש בעברית מה עובד ומה לא, עם צילומי מסך, ולהציע סדר תיקונים.
