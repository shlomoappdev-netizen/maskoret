# מחשבון שכר — אפליקציית Mac

אפליקציית SwiftUI נייטיב ל-macOS לחישוב הכנסה חודשית: ברוטו → ניכויים (מחושבים אוטומטית לפי נתוני המדינה) → נטו → הוצאות קבועות → רכישות תקופתיות → יתרה.

## התקנה ועדכונים

האפליקציה מותקנת ב-`/Applications/מחשבון שכר.app` ונפתחת כמו כל אפליקציה (Launchpad / Spotlight).
הנתונים נשמרים ב-`~/Library/Application Support/Maskoret/` ולא נמחקים בעדכון.

**איך עדכון עובד:** גרסה חדשה מגיעה כקוד לתיקייה הזו יחד עם `version.json` (עם מספר `build` גבוה יותר).
האפליקציה בודקת את הקובץ בכל פתיחה, ובמסך **עדכונים** (או בכפתור "עדכון זמין" בתחתית סרגל הצד) לוחצים **עדכן עכשיו**:
היא בונה את הגרסה עם Xcode שמותקן במחשב (כדקה), מחליפה את עצמה ב-Applications ונפתחת מחדש.

### איך מוציאים גרסה חדשה (למפתח / ל-Claude)

1. משנים את הקוד בתיקייה `Maskoret/`.
2. מעדכנים את `version.json`: מעלים את `build` ב-1, משנים `version` ו-`notes`.
3. מעדכנים גם `MARKETING_VERSION` ו-`CURRENT_PROJECT_VERSION` ב-`project.pbxproj` לאותם ערכים.
4. אם השתנו שיעורי מס — מעדכנים את `rates/tax-rates.json` ומעלים בו את `version`.

הרצה מ-Xcode: בוחרים **My Mac** ולוחצים ▶︎. אין צורך ב-Apple ID — האפליקציה חתומה מקומית.

## גרסת אייפון / אייפד

באותו פרויקט יש target נוסף, **MaskoretiOS**: אפליקציה נייטיב (SwiftUI) שמשתמשת באותו קוד בדיוק, עם טאבים בתחתית (סיכום · תנועות · כרטיס אשראי · חשבונות · עוד).

**התקנה על האייפון (בחינם, עם Apple ID רגיל):**
1. מחברים את האייפון למחשב בכבל (או באותה רשת Wi‑Fi אחרי חיבור ראשון) ומאשרים ״סמוך על המחשב הזה״.
2. ב-Xcode: בוחרים למעלה את הסכמה **MaskoretiOS** ואת האייפון כיעד.
3. בפעם הראשונה: Xcode ← Settings ← Accounts ← מוסיפים Apple ID. ואז בפרויקט ← target **MaskoretiOS** ← Signing & Capabilities ← בוחרים את ה-Team (Personal Team).
4. לוחצים ▶︎. באייפון: הגדרות ← כללי ← VPN וניהול מכשירים ← מאשרים את המפתח. וגם: הגדרות ← פרטיות ואבטחה ← מצב מפתח ← מפעילים.

עם Apple ID חינמי האפליקציה תקפה ל-7 ימים. אחרי זה מחברים ולוחצים ▶︎ שוב, והנתונים נשמרים. עם חשבון מפתח בתשלום ($99 לשנה) היא תקפה לשנה ואפשר להתקין גם דרך TestFlight.

באייפון אין את המודל המובנה (MLX). תובנות AI עובדות דרך מודל בענן או במצב ידני.

## חשבונות, משקי בית וסנכרון (Supabase)

הנתונים מסתנכרנים דרך Supabase, בפרויקט **Maskoret** (`pukbrxsuucqrukiaojlp`, eu-central-1).
- כתובת הפרויקט והמפתח הציבורי נמצאים ב-`Maskoret/SupabaseConfig.swift`.
- המפתח הציבורי מותר להיות בתוך האפליקציה. מה שכל משתמש רשאי לראות ולשנות נקבע במסד הנתונים.

**חשבון:**
- מייל וסיסמה, עם אימות בקוד בן 6 ספרות במייל.
- "שכחתי סיסמה" עובד גם הוא עם קוד במייל.
- אפשר להמשיך גם בלי חשבון, ואז הנתונים נשמרים רק במכשיר.

**משק בית:**
- כל משק בית הוא סט נתונים שלם (הכנסות, הוצאות, חשבונות, בני משפחה), ומשותף לכל החברים בו.
- משתמש יכול להיות חבר בכמה משקי בית (עד 20) ולעבור ביניהם.
- יש שני תפקידים: **בעלים**, שמזמין, מסיר חברים, משנה שם ומוחק, ו**חבר**, שרואה ועורך.
- הזמנה היא קוד בן 8 תווים, בתוקף 7 ימים ולשימוש אחד.

**הסנכרון:**
- הקבצים במכשיר נשארים עותק העבודה, ולכן האפליקציה עובדת גם בלי אינטרנט.
- כל שינוי נשמר בשרת אחרי כ-2 שניות, וכל שמירה מקבלת מספר גרסה (revision).
- המכשירים האחרים מקבלים את העדכון מיד (Realtime). בנוסף יש בדיקה כל דקה, וגם כשהאפליקציה חוזרת לפוקוס.
- אם שני מכשירים שינו נתונים באותו זמן, הגרסה החדשה יותר נשמרת, והשנייה נשמרת כגיבוי במסך גיבוי ושחזור.
- השרת שומר את 30 הגרסאות האחרונות של כל משק בית (`household_snapshots`).

**מסד הנתונים:**
- הטבלאות: `profiles`, `households`, `household_members`, `household_invites`, `household_data`, `household_snapshots`.
- לכל הטבלאות יש RLS. אפשר לקרוא מהן ישירות, אבל כל כתיבה עוברת דרך פונקציות: `create_household`, `save_household_data`, `create_invite`, `accept_invite`, `leave_household`, `remove_member`, `rename_household`, `delete_household`, `delete_my_account`.

**ניהול משתמשים:** החשבון המאומת `<admin email>` הוא מנהל המערכת. רק הוא רואה את המסך **ניהול משתמשים**, שם מוצגים כל החשבונות ומשקי הבית, ואפשר למחוק חשבון או משק בית. הנתונים הכספיים עצמם לא מוצגים במסך. ההרשאה נבדקת בשרת בכל פעולה (`private.is_admin`, `admin_overview`, `admin_delete_user`, `admin_delete_household`). המיגרציות נמצאות ב-`supabase/migrations/`.

**לפני פתיחה לקהל רחב:**
1. **שרת מיילים משלך (SMTP):** השרת המובנה של Supabase שולח רק לכתובות של חברי הצוות בארגון ומוגבל בכמות. צריך לחבר שירות כמו Resend בלוח הבקרה, ב-Auth ← SMTP.
2. **תוכנית בתשלום ב-Supabase:** בתוכנית החינמית אין גיבויים יומיים, ופרויקט בלי פעילות שבוע עובר להשהיה.
3. **הפצה:** חשבון מפתח של Apple, מדיניות פרטיות ותנאי שימוש, ו-Sign in with Apple אם מוסיפים התחברות חיצונית.

## הפצה ועדכונים לכולם

- **אתר ההורדות:** https://shlomoappdev-netizen.github.io/maskoret-releases/. זה מאגר ציבורי, `shlomoappdev-netizen/maskoret-releases`, שמכיל רק קובצי התקנה ודפי אתר. הקוד עצמו נשאר במאגר הפרטי.
- **`latest.json` באתר:** כל האפליקציות בודקות את הקובץ הזה כדי לדעת אם יש גרסה חדשה. השדה `build` הוא המספר שמשווים אליו.
- **מק:** אם במחשב יש את תיקיית הפרויקט, העדכון ממשיך לבנות מקוד המקור. בכל מחשב אחר, האפליקציה מורידה את ה-DMG מהאתר, בודקת את החתימה (SHA-256), מתקינה ונפתחת מחדש.
- **אנדרואיד ו-Windows:** מורידים מהאתר. בדיקת העדכונים בתוך האפליקציה נמצאת בעבודה בגרסת ה-Flutter.
- **אייפון:** הפצה לאחרים דורשת חשבון מפתח בתשלום (TestFlight).

**איך מפרסמים גרסה חדשה:**
1. מעלים את `version` ואת `build` ב-`version.json`, ומעדכנים את ה-`notes`.
2. מעדכנים את ה-APK ואת ה-ZIP של Windows בתיקייה `להפצה`.
3. מריצים את `tools/publish_release.sh`. הסקריפט בונה את המק, מעלה את שלושת הקבצים כגרסה חדשה ב-GitHub ומעדכן את `latest.json`.

| **הוצאות קבועות** | הוצאות חודשיות — ₪ או אחוז מהנטו |
| **מעקב רכישות** | רכישות מחוץ לתלוש שחוזרות מדי פעם (נעליים, בגדים, טלפון…). "קניתי חדש" בכל קנייה → כמה זמן זה החזיק, ממוצע, עלות לחודש, צפי החלפה. העלות החודשית יורדת מהיתרה |
| **היסטוריה** | חודשים שמורים, גרף מגמה וממוצעים |
| **נתוני מס** | נקודות זיכוי, השיעורים הרשמיים ומקורות |
| **חשבון ומשק בית** | התחברות, סנכרון, מעבר בין משקי בית, הזמנת חברים וניהול החשבון |
| **עדכונים** | הגרסה הנוכחית, בדיקה והתקנה של גרסה חדשה |
